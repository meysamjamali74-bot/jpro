# Enterprise 1.2

Production focus: Treasury + Bank/POS Reconciliation + Distribution/POD + Commission.

Acceptance requires:
1. Accounting-backed receipt/payment with idempotent source-to-ledger traceability.
2. Bank reconciliation import, suggestion, confirm and unmatch.
3. Payment proposal and short-horizon cash forecast.
4. Trip lifecycle with load, gate/dispatch, delivery/POD, return, collection handover and settlement.
5. Cold-chain temperature event support.
6. Commission based on posted invoices and actual receipt allocation, with gross-profit option, tiers, target and clawback.
7. Persian UI and server-side list controls.
8. MySQL 8.4 E2E tests and Windows/Web release gates.
