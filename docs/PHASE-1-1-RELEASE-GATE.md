# TARAZPAD Enterprise 1.1 Release Gate

Merged from `enterprise-phase-1-1` after the following gates passed on the branch:

- Tarazpad CI
- Tarazpad Enterprise Strict Gate
- Tarazpad Web Release
- Tarazpad Native Windows Server Installer, including first-install and second-run idempotency

Scope includes Iranian tax invoice controls, VAT/effective tax rates, purchase/AP and 3-way match, GRNI, controlled chart of accounts, rich party masters, employee/contracts, attendance, loans, payroll calculation and accounting posting, Persian terminology, and scalable list filtering/pagination.

This document is a release checkpoint, not a statement that all master ERP scope is complete.
