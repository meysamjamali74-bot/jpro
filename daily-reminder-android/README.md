# یادآور روزانه — نسخه بومی اندروید

برنامهٔ اندروید با رابط وب Base44 و زنگ بومی ۵ ثانیه‌ای برای کارهایی که از طریق رابط وب با گوشی همگام شده‌اند.

## نحوه نصب
1. از GitHub Actions این شاخه، فایل `daily-reminder-android-apk` را دریافت و از ZIP خارج کنید.
2. فایل `app-debug.apk` را روی گوشی اندروید نصب کنید. برای نصب خارج از فروشگاه ممکن است اجازهٔ Install unknown apps لازم باشد.
3. وارد حساب کاربری برنامه شوید و دسترسی اعلان را تأیید کنید.
4. دکمه «مجوز زنگ دقیق» را بزنید و Allow exact alarms را فعال کنید.
5. در تنظیمات باتری گوشی، برای برنامه محدودیت پس‌زمینه را بردارید و در صورت وجود Auto-start را فعال کنید.
6. در برنامه یک کار آزمایشی برای ۲ دقیقه بعد ثبت کنید؛ برنامه را ببندید، صفحه را قفل کنید و عملکرد را بررسی کنید.

## طراحی
- WebView فقط دامنه `https://app-f7e51b47.base44.app` را در برنامه باز می‌کند.
- برنامه وب پس از بارگذاری موفق فهرست کارها را با پل `AndroidReminder.syncTasks` به لایه بومی می‌فرستد.
- لایه بومی، زمان‌ها را در SharedPreferences خصوصی نگهداری می‌کند و با AlarmManager زنگ‌های اندروید را تنظیم می‌کند.
- با رسیدن زمان، BroadcastReceiver یک ForegroundService با صدای STREAM_ALARM و اعلان راه‌اندازی می‌کند و پس از ۵ ثانیه متوقف می‌شود.
- پس از راه‌اندازی مجدد گوشی، زنگ‌های آینده مجدداً ثبت می‌شوند.

## محدودیت‌ها
- اگر مجوز Exact alarms داده نشود، اندروید ممکن است زنگ را با تأخیر اجرا کند.
- اگر گوشی توسط سازنده محدودیت سختگیرانهٔ باتری اعمال کند، عملکرد باید روی دستگاه واقعی آزموده شود.
- کارهای جدیدی که از راه دور و در زمان بسته‌بودن کامل برنامه ایجاد می‌شوند تا همگام‌سازی بعدی، روی گوشی آلارم بومی ندارند. این نسخه هنوز پوش بلادرنگ ندارد.
- این فایل APK از نوع debug-signed است؛ برای انتشار عمومی باید نسخه release با امضای اختصاصی تهیه شود.
- این نسخه به اینترنت برای ورود و همگام‌سازی نیاز دارد؛ آلارم‌های همگام‌شده بدون اینترنت نیز اجرا می‌شوند.
